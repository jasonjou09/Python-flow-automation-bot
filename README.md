# Tax Billing Complete GUI System

Tax Billing Complete GUI System 是專為會計與記帳事務所設計的自動化帳務管理系統。系統以 Python Tkinter 構建直覺的操作介面，後台整合關聯式資料庫（SQLite）、光學字元辨識（Tesseract OCR）與自動化辦公技術（OpenPyXL），實現從國稅局報稅 PDF 讀取、金額辨識入庫、產生 Excel 請款單，到自動回寫年度客戶收款總表的完整自動化工作流。

## 系統核心特色

* 關聯式資料庫設計：採用三表正規化架構（公司主檔、期別帳單、動態特別項目），引入隱藏內部 ID 關聯，完美支援公司編號釋出與新客戶遞補，確保歷史帳務軌跡完整不丟失。
* 歷史快照鎖定：建立期別底冊時自動帶入當期記帳費並實施快照鎖定，避免因日後調整標準記帳費而竄改過去已結案的歷史帳目。
* 智慧 OCR 金額辨識：批次讀取國稅局 PDF，自動裁切金額區域並辨識入庫，內建防覆蓋機制，防止手動微調過的營業稅資料被重複執行的 OCR 覆蓋。
* 動態特別項目管理：支持單一客戶在同一期內新增多筆不固定的特別繳款項目（如代辦費、規費等）。
* 一鍵請款單生成：自動讀取 Excel 範本填入對應期別、稅費、動態項目與備註，自動排版另存並即時開啟。
* 收款自動化回寫：點擊確認付款後，系統排除營業稅，僅將「記帳費 + 特別項目總金額」精準回寫至年度客戶帳單明細總表的對應期別與列數。

## 系統架構

### 資料庫架構 (SQLite)

* companies：客戶基本資料維護表，包含內部 ID、公司編號、公司名稱、統一編號、每期標準記帳費、銀行帳號、啟用狀態。
* billing_records：期別帳款明細表，包含公司內部 ID 外鍵、年份、雙月期別、營業稅、記帳費、備註、請款狀態、付款狀態。
* billing_special_items：動態特別項目表，一對多關聯期別帳款，記錄額外特殊項目的名稱與金額。

## 安裝與配置

### 1. 系統環境需求
* Windows 10 / 11 系統 (推薦)
* Python 3.8 或以上版本
* Tesseract-OCR 引擎

### 2. 安裝 Python 依賴套件
```bash
pip install pandas openpyxl pypdf pytesseract Pillow pywin32

```

### 3. 配置 Tesseract-OCR

1. 安裝 Windows 版本的 Tesseract-OCR。
2. 請確保其安裝路徑為：`C:\Program Files\Tesseract-OCR\tesseract.exe`。若為其他路徑，請手動更新程式碼中的 `pytesseract.pytesseract.tesseract_cmd` 變數。

## 專案結構與必要檔案

請確保執行程式時，目錄結構包含以下必備檔案：

```text
├── main_app_v1.1_beta.py        # 系統主程式
├── 範本.xlsx                     # 請款單 Excel 範本 (格式須與程式對應)
└── 115年01-12月客戶帳單明細.xlsx  # 當年度明細總表 (檔名年份需與系統設定相同)

```

### Excel 檔案格式說明

#### 1. 範本.xlsx

* B2 儲存格：寫入公司完整名稱。
* B4、C4 儲存格：寫入營業稅名目與金額。
* B5、C5 儲存格：寫入記帳費名目與金額。
* B6 ~ B9、C6 ~ C9 儲存格：寫入動態特別項目名稱與金額（上限 4 筆）。
* D9 儲存格：寫入備註。

#### 2. 民國年01-12月客戶帳單明細.xlsx

* 分頁名稱須為對應民國年（如 `115年`）。
* A 欄為公司編號，與系統中的公司編號一致。
* D、E、F、I、J、K 欄分別對應「01-02月」、「03-04月」、「05-06月」、「07-08月」、「09-10月」、「11-12月」的收款總額（不含營業稅）。

## 操作說明

1. 啟動系統後，在頂部設定民國年份。
2. 點擊「1. 匯入請款表 (比對底冊)」自動建立全年度各期帳款底冊。
3. 點擊「2. 匯入對照表」匯入 5 欄位格式的客戶基本資料（公司編號、名稱、統一編號、記帳費、銀行帳戶）。
4. 點擊「3. 讀取 PDF 擷取圖片」選取國稅局 PDF 批次匯出統編圖片。
5. 點擊「4. OCR 辨識金額入庫」選取圖片資料夾，系統將辨識營業稅並寫入。
6. 於右側編輯區手動微調數據，並可動態新增特別項目。
7. 點擊「產生請款單」生成 Excel 並自動開啟；點擊「確認已付款」將金額回寫至明細總表。
8. 前往「公司基本資料維護」分頁可對客戶主檔進行新增、停用或啟用調整。
